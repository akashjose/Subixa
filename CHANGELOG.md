# Changelog

Written by release-please from the conventional-commit prefixes on master, not
by hand — an edit here is overwritten by the next release pull request. The
prefix on a commit is what decides whether it appears below and what it does to
the version number; [`docs/releasing.md`](docs/releasing.md) says which does
what.

Nothing appears here from before the first release. What stood here was a
milestone diary, written when there was no version to organise it by; it read as
history rather than as a changelog, and it is in the git log, which is where
that account belongs. [`docs/roadmap.md`](docs/roadmap.md) is the
forward-looking half.
